# Contributing

Thanks for helping improve **Awesome Agent Observability**! This list aims to be a high-signal, practitioner-focused collection — quality over quantity.

## What belongs here

Tools, frameworks, standards, and benchmarks specifically for the **observability, evaluation, tracing, guardrails, and red-teaming of LLM agents**. When in doubt, ask: *does this help someone understand, measure, or constrain a production agent?*

## What does not belong here

- Generic APM / infra monitoring with no first-class LLM or agent support.
- Agent *frameworks* themselves (LangChain, CrewAI, etc.) — they belong on other lists.
- Abandoned projects (no commits in ~12 months) or dead links.
- Pure marketing pages with no usable product or open-source component.

## How to add an entry

1. Fork the repository and create a branch.
2. Add your entry to the most appropriate category, keeping each category alphabetical where it already is, or grouped sensibly.
3. Use the standard format:

   ```
   - [Name](https://link) — One-line description ending with a period.
   ```

   - Use an em dash (`—`) between the link and the description.
   - Keep descriptions to a single, factual line. No hype, no "best", no emoji.
   - Link to the canonical source (usually the GitHub repo or official docs).

4. **Verify your link resolves** (HTTP 200 or a clean redirect) before opening the PR.
5. Open a pull request describing what the tool does and why it fits.

## Adding a new category

If your entry doesn't fit an existing category, propose a new one in your PR and add it to the Table of Contents.

## Quality bar

Maintainers may decline entries that are redundant, low-quality, off-scope, or unverifiable. That's not personal — it keeps the list useful.
